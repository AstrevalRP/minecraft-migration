# 1.20.5 / 1.20.6

## Remplacement du NBT des ItemStack par les DataComponents

C'est le changement le plus impactant de cette version pour les mods manipulant des items. Le système `CompoundTag` (NBT) directement attaché aux `ItemStack` est **remplacé** par un système de composants typés (`DataComponents`).

### Avant (≤ 1.20.4)

```java
// Lire
CompoundTag tag = stack.getTag(); // null si absent
if (tag != null && tag.contains("MyKey")) {
    int value = tag.getInt("MyKey");
}

// Écrire
CompoundTag tag = stack.getOrCreateTag();
tag.putInt("MyKey", 42);

// Tester
boolean has = stack.hasTag();
```

### Après (≥ 1.20.5)

```java
// Lire
CustomData data = stack.get(DataComponents.CUSTOM_DATA);
if (data != null && data.contains("MyKey")) {
    int value = data.copyTag().getInt("MyKey");
}

// Écrire
stack.update(DataComponents.CUSTOM_DATA, CustomData.EMPTY, existing -> {
    CompoundTag tag = existing.copyTag();
    tag.putInt("MyKey", 42);
    return CustomData.of(tag);
});

// Tester
boolean has = stack.has(DataComponents.CUSTOM_DATA);
```

### Points d'attention

- `CustomData` est **immutable** — il faut utiliser `copyTag()` pour lire puis recréer via `CustomData.of(tag)` pour écrire.
- `stack.update()` est la méthode idiomatique pour modifier un composant existant.
- Les données persistées en NBT dans les mondes anciens sont automatiquement migrées par le `DataFixer` vanilla — pas besoin de migration manuelle.
- `stack.getItem().getDescriptionId()` reste accessible, mais `stack.getItem().getRegistryEntry()` est la façon moderne d'accéder à l'entrée de registre.

### Autres composants utiles

| `DataComponents.*` | Contenu |
|---|---|
| `CUSTOM_DATA` | NBT arbitraire du mod (remplace `getTag()`) |
| `DAMAGE` | durabilité actuelle |
| `MAX_DAMAGE` | durabilité max |
| `CUSTOM_NAME` | `Component` du nom custom |
| `LORE` | liste de `Component` |
| `ENCHANTMENTS` | `ItemEnchantments` |
| `CUSTOM_MODEL_DATA` | int du model data |

## `ItemStack` — méthodes supprimées

| Ancienne méthode | Remplacement |
|---|---|
| `stack.getTag()` | `stack.get(DataComponents.CUSTOM_DATA)` |
| `stack.setTag(tag)` | `stack.set(DataComponents.CUSTOM_DATA, CustomData.of(tag))` |
| `stack.getOrCreateTag()` | `stack.update(DataComponents.CUSTOM_DATA, ...)` |
| `stack.hasTag()` | `stack.has(DataComponents.CUSTOM_DATA)` |
| `stack.removeTagKey("X")` | `stack.update(...)` puis supprimer la clé du tag |
