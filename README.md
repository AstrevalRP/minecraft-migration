# minecraft-migration

Le but de ce repo est de lister les différents changements de chaque version de minecraft dans un fichier markdown dédié (exemple : `1.21.6.md`, `1.21.6.md`, ...), tout en excluant ce qui est déjà indiqué dans le blog de Fabric.
Cela permettra ainsi de mettre à jour des mods plus facilement sans avoir à deviner les changements
