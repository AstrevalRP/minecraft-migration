# 1.21.8

## Gradle — Loom 1.17 requiert Gradle 9.5.0

### Problème / changement observé

Loom 1.17.x (requis pour 1.21.8) n'est pas compatible avec Gradle 9.2.0. Le build échoue avec une erreur `No matching variant` mentionnant `org.gradle.plugin.api-version` 9.5.0 vs 9.2.0.

```properties
# gradle/wrapper/gradle-wrapper.properties — avant
distributionUrl=https\://services.gradle.org/distributions/gradle-9.2.0-bin.zip

# après
distributionUrl=https\://services.gradle.org/distributions/gradle-9.5.0-bin.zip
```

> Utiliser loom 1.17.17 (stable) plutôt que 1.17-SNAPSHOT, les deux nécessitent Gradle 9.5.

## Loom 1.17 — tâche compileGametestJava supprimée

### Problème / changement observé

La tâche `compileGametestJava` n'existe plus dans Loom 1.17. Utiliser `compileTestJava` à la place. Les gametests sont lancés via `runGametest` (minuscule, pas `runGameTest`).

```bash
# avant
./gradlew compileGametestJava

# après
./gradlew compileTestJava
```
