# 1.20.2

## Renommage des dossiers de données

Même logique que 1.21.5 (voir `1.21.5.md`) : les dossiers de données vanilla passent au singulier.

| Ancien nom | Nouveau nom |
|---|---|
| `advancements/` | `advancement/` |
| `tags/items/` | `tags/item/` |
| `tags/blocks/` | `tags/block/` |
| `tags/entity_types/` | `tags/entity_type/` |
| `tags/fluids/` | `tags/fluid/` |
| `tags/game_events/` | `tags/game_event/` |

Comme pour les recettes en 1.21.5, le jeu charge silencieusement les anciens noms dans certains cas via fallback, mais ce comportement est non garanti et a été supprimé progressivement.

## Registres — passage au système `RegistryKey`

Le système de registre a été refactorisé. L'accès aux registres se fait désormais via `RegistryKey` et les `RegistryWrapper` / `RegistryEntryLookup`, notamment dans la génération de données (`DatagenHandler`).

Les méthodes `Registry.register()` restent disponibles mais les signatures ont changé dans certains contextes (worldgen surtout).
